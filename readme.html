Run locally

open Aretay.xcodeprojthen press ⌘R

SUPABASE_URLlocal: http:/$()/127.0.0.1:54321 · prod: from Supabase dashboard
SUPABASE_ANON_KEYfrom ./run-backend.sh keys or Supabase dashboard

aretay-backend

github.com/WillReynolds5/aretay-backend →

Supabase project providing Postgres, Auth, Storage, and Edge Functions. Migrations live in supabase/migrations/ and are deployed to prod automatically on push to main via GitHub Actions.

Stack

Supabase Postgres 17 Row Level Security Supabase Auth Supabase Storage

Run locally

./run-backend.sh startboots local Supabase stack in Docker
./run-backend.sh keysprints SUPABASE_URL + ANON_KEY for Secrets.xcconfig
./run-backend.sh new <name>creates a new timestamped migration file
./run-backend.sh pushpushes local migrations to linked prod project
./run-backend.sh stopshuts down local stack

aretay-admin

Local-only Next.js admin console for seeding courses and producing course videos with Remotion. Not deployed — run it on your machine.

Stack

Next.js 16 (App Router) React 19 Tailwind CSS 4 Remotion 4 Supabase JS

Run locally

./run-admin.shinstalls deps if needed, starts Next.js at localhost:3000
npm run studio --prefix aretay-adminopens Remotion Studio at localhost:3001

Pages

RouteDescription
/Course list — create, view, and delete courses in Supabase.
/courses/[id]Video studio — Remotion Player preview + CLI render command for the selected course.

Video compositions

CompositionDescription

Render a video

npx remotion render remotion/index.ts CourseVideo out/<id>.mp4 --props='…' renders to MP4 locally — command shown on each course's studio page
